# v31 局部白芯排布

参考数据：A高低双区质心0.904H/0.311H，B主区0.533H/0.637H，C主区0.649H与细区0.801H。三图没有连续时间戳，所以这些数据作为空间排布约束，而非逐帧精确目标。

实现：对每个体积采样点使用所属字形的归一化坐标 gx 与 altitude。主亮区中心高度 h0=phase+0.13+drift*0.10，横向中心 x0=0.36+(noise-0.5)*0.32。主区高/宽尺度为0.19H/0.30字宽，侧区比主区低0.15H，细区比主区高0.19H。三组高斯亮区权重为1/0.58/0.28，再乘局部体积纹理折叠权重；白芯仍受燃料、温度和燃烧退场控制。参考截图本身不能唯一确定这些公式，以上系拟合实现参数。

白芯占比验证：原24.5%分类规则，8个时间点1/1.6/2.2/2.8/3.4/4/4.6/5.2秒，排除暗蓝光晕、文字底色、少于1000像素的连通区域，白芯153973像素/较亮火焰628371像素=24.5035%。面积加权合计，不代表每帧恒定。增益690为此程序的校准系数，并非物理值。
