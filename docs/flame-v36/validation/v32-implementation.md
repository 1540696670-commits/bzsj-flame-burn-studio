# v32 固定视角顺时针绕烧

绕字形竖轴，俯视方向顺时针。归一化横向/深度为X=(x−cx)/rx、Z=(z−0.5)/0.27，速度增量vx=ωrxZ，vz=−ω0.27X。ω=2.4(0.85+0.30noise)rad/s，平均约2.4rad/s，完整绕行约2.6秒。15度是绕行热带相对水平面倾斜角，tan15°=0.267949；热源高度按横向位置偏移，非相机旋转。局部不规则上升流仍参与运动，不是刚性旋转动画。

渲染视角固定。前半体积发光后，在文字面处以文字已显露alpha衰减后半体积透射，表现后方被字形遮挡；这是体积与字形平面遮挡近似，并非完整实体网格碰撞模拟。角度与方向按本次用户描述设定，不是从截图反推的测量值。
